REQUERIMIENTOS FUNCIONALES
1. El sistema debe poder permitir registrar un prompt
2. El sistema debe entender el lenguaje del archivo
3. El sistema debe poder generar codigo bien estructurado
4. El sistema debe de soportar diferentes solicitudes.
5. El sistema debe generar el codigo correspondiente.
REQUERIMIENTOS NO FUNCIONALES
1. El sistema debe responder en un tiempo menor a 5 segundos
2. El sistema debe tener una disponibilidad del 90%
3. El sistema debe recuperarse automaticamente ante los fallos en menos 60 segundos
4. El sistema debe permitir utilizar el sistema sin capacitación previa en menos de 10 minutos
5. El sistema debe tener una arquitectura modular para facilitar futuras mejoras y mantenimientos
